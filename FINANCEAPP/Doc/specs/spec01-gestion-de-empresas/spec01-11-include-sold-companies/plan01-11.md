## 1. Enfoque

- **Sin cambios de esquema.** Lo vendido se calcula al leer, a partir de `SalesHistory` y de las compras cerradas (`Operations.SaleHistoryId`). La preferencia va en `AppSettings`, que ya existe.
- **La lógica, en `Services/`** (constitución, principio 3):
  - un método nuevo en `IPortfolioPeriodService` reúne lo vendido de la vista;
  - una clase estática nueva, `SoldPositionsSummary`, lo suma a los totales y a las filas;
  - la página solo elige qué mostrar.
- **Conversión con los tipos guardados** (SPEC-02-05): se reutiliza la lógica de `ExchangeRateService.GetConvertedSaleTotalsAsync`, sacando su parte «por venta» a un método que devuelve cada venta convertida. Los totales de `/sales-history` deben seguir dando lo mismo.
- **«Cartera actual» no cambia nada:** si el selector está ahí, la página sigue exactamente el camino de hoy.

## 2. Modelo de datos (solo clases en memoria)

En `IExchangeRateService.cs`:

```csharp
public class ConvertedSale            // una venta convertida a la divisa base
{
    public int SaleHistoryId; public string CompanyName; public DateTime SaleDate;
    public decimal Shares;            // acciones vendidas
    public decimal Cost;              // Σ importe de las compras cerradas × su tipo
    public decimal NetProceeds;       // (importe − comisión de la Venta) × tipo de la Venta
    public bool Approximate;          // algún tipo actual en lugar del guardado, o coste del registro
    public List<ConvertedSaleLot> Lots;   // compras cerradas: Id, fecha, acciones, coste convertido
}
```

En `IPortfolioPeriodService.cs`:

```csharp
public enum SoldStatus { Sold, Partial }

public class SoldSummary
{
    public decimal Cost, NetProceeds;                         // suma de la vista
    public Dictionary<string, SoldCompany> ByCompany;          // por nombre de empresa
    public int ApproximateSales, MissingRateSales, DeletedCompanySales;

public class SoldCompany { public decimal Cost, NetProceeds; public SoldStatus Status; }
```

`Realized` (= NetProceeds − Cost) se calcula al leer.

## 3. Algoritmos

### 3.1 `ExchangeRateService.GetConvertedSalesAsync(sales, currencyByCompany)` (nuevo)

1. Por cada venta, como hoy en `GetConvertedSaleTotalsAsync`:
   - **Tipo de la Venta:** el guardado; si no vale, el actual y la venta queda aproximada; si no hay ninguno, cuenta como `MissingRate`.
   - **Coste:** por cada compra cerrada (`SaleHistoryId`), `Amount` (precio × acciones + comisión) × su tipo guardado, o el actual si falta (aproximada).
   - **Sin compras enlazadas** (venta antigua o compras borradas): `AverageBuyPrice × acciones + comisión de compra` con el tipo actual, y aproximada.
   - **Cobrado neto:** `(Amount − Commission de la operación Venta) × tipo de la Venta`.
2. **En la divisa base** no hay conversión, pero sí el mismo reparto, así que en su divisa `NetProceeds − Cost = Profit`.
3. **`GetConvertedSaleTotalsAsync` pasa a sumar lo que devuelve este método,** sin cambiar sus resultados.

### 3.2 `PortfolioPeriodService.GetSoldAsync(filter, view)` (nuevo)

1. Empresas por nombre (`LoadCompaniesAsync`). Las ventas cuya empresa ya no existe se cuentan en `DeletedCompanySales` y se descartan.
2. Ventas convertidas con 3.1.
3. **Según la vista:**
   - **Total histórico** (`filter.Mode == All`): todas las ventas.
   - **«Cartera al cierre»**: ventas con `SaleDate ≤ corte` (mismo corte que `GetClosingSummaryAsync`).
   - **«Compras del periodo»**: de cada venta, solo los lotes con fecha en el periodo. El coste es el del lote y el cobrado, `NetProceeds × acciones del lote ÷ acciones de la venta`.
4. **Estado de cada empresa:** `Sold` si en la vista no le quedan acciones, `Partial` si le quedan.
   - Hoy: `NumberOfShares > 0`.
   - Al cierre: posición en el corte.
   - En compras: lotes del periodo aún abiertos.

### 3.3 `SoldPositionsSummary` (estática, en `Services/`)

- `Combine(ConvertedCompanyTotals open, SoldSummary sold, decimal soldDividends)` → totales nuevos:
  - `InvestedInitial += Cost`;
  - `CurrentValue += NetProceeds`;
  - `Dividends += soldDividends`;
  - `InitialByCompanyId` sin tocar, para que el peso siga siendo el de la cartera abierta.
- `Rows(IEnumerable<CompanyDetail> open, IEnumerable<CompanyDetail> all, SoldSummary sold)` → copias para el listado:
  - **Parcial:** copia de la fila abierta con inversión y valor sumados y la rentabilidad recalculada.
  - **Vendida:** copia de la empresa con `TotalInvestedInitial = Cost`, 0 acciones, `TotalInvestedValue = NetProceeds` y la rentabilidad por precio = realizado ÷ coste. Van al final.
  - Devuelve también `Dictionary<int, SoldStatus>` para chips y color.
- **Dividendos de las vendidas:** con Total histórico, `TotalDividends` de las empresas `Sold` convertido con el tipo actual, como los demás dividendos de hoy. En las vistas de periodo se mantiene su regla: «Compras del periodo» ya cuenta los dividendos del periodo de todas las empresas, y «Cartera al cierre» los dividendos con fecha ≤ corte de las empresas incluidas, que ahora son también las vendidas.
- Las fórmulas de rentabilidad no cambian: `WeightedReturnPercent` y `WeightedReturnWithDividendsPercent` reciben los totales combinados.

### 3.4 Página `CompaniesList.razor`

1. `includeSold` se carga de `IAppSettingsService.GetCompaniesIncludeSoldAsync()` y se guarda al cambiar.
2. Selector de dos botones con el mismo estilo que «Vista del periodo».
3. Con `includeSold`:
   - `CardTotals` y `CardCompanies` usan lo combinado;
   - el listado corto y la lista extendible usan las filas de `SoldPositionsSummary.Rows`;
   - chip «Vendida» / «Parcial» y la clase `.row-sold` para las vendidas del todo;
   - los botones de fila con `RealCompany`, como en SPEC-01-10.
4. **Avisos:** «lo vendido usa los tipos de cada venta», ventas aproximadas, sin tipo y de empresas borradas. La nota «ya vendidas» de «Compras del periodo» se oculta con `includeSold`.
5. En la lista extendible, el peso de las vendidas del todo muestra «—».

## 6. Casos límite (cómo se tratan)

- **Sin ventas en la vista:** `SoldSummary` vacío, y lo combinado es igual a lo abierto.
- **Venta antigua sin registro:** no está en `SalesHistory`, así que no entra (sigue restando como hoy).
- **Lote partido:** la fila cerrada está en `Lots` y la abierta en lo abierto; no hay duplicados porque son filas distintas.
- **Recompra tras vender:** estado `Partial`.
- **Venta sin tipo:** `MissingRateSales`, fuera y con aviso.
