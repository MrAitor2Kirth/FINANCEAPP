## 2. Modelo (clases en memoria, en `IPortfolioPeriodService.cs`)

```csharp
public enum BreakdownLineKind { OpenLot, OldSale, Sale, Dividend }

public class BreakdownLine
{
    public BreakdownLineKind Kind; public DateTime Date; public string Label;   // «Compra», «Traspaso», «Venta», «Venta antigua», «Dividendo»
    public decimal? Shares; public decimal? Price;                             // precio por acción (null = «—»)
    public decimal Cost;                                                       // importe con comisión (negativo en venta antigua)
    public decimal? Value;                                                     // lote: acciones × precio; venta: cobrado neto; dividendo: importe
    public decimal? Result; public decimal? ResultPercent;
}

public class CompanyBreakdown
{
    public string CompanyName; public string CurrencyCode; public List<BreakdownLine> Lines;
    public decimal Invested, Value, Dividends;           // totales en la divisa de la empresa (redondeados al final)
    public decimal Result => Value - Invested;
    public decimal? ReturnPercent, ReturnWithDividendsPercent;
    public bool ShowReturnWithDividends;                 // false en «Compras del periodo»
    public List<string> Warnings;                        // sin precio de cierre, ventas aproximadas…
}
```

## 3. Algoritmo · `GetBreakdownAsync(companyName, filter, view, includeSold, ct)`

1. **Empresa:** se carga con su divisa (`LoadCompaniesAsync`, ya corregido en SPEC-01-11). Si no existe, se devuelve null.
2. **Operaciones de la empresa** (por nombre), sin seguimiento.
3. **Lotes y precio según la vista:**
   - **Total histórico:** lotes = Compra/Traspaso con `CloseDate == null`; ventas antiguas = Venta con `CloseDate == null`; precio = `LivePrice ?? CurrentPrice`; dividendos = todos.
   - **«Compras del periodo»:** lotes abiertos con fecha en el periodo; precio de hoy; sin dividendos (`ShowReturnWithDividends = false`).
   - **«Cartera al cierre»:** lotes con fecha ≤ corte y `CloseDate` nulo o posterior; ventas antiguas igual; precio de cierre en el corte (helper compartido con `GetClosingSummaryAsync`: `EnsureDailyCoverageAsync` + `GetDailyCloseAtAsync`, con aviso si falta); dividendos ≤ corte.
4. **Línea por lote:**
   - coste = `Amount`;
   - valor = acciones × precio;
   - resultado y % = (valor − coste) ÷ coste;
   - precio de compra = `PricePerShare` (null si es 0).
5. **Venta antigua:** coste = −`Amount`, acciones negativas, sin valor (como resta hoy `RecalculateTotalInvestedAsync`).
6. **Ventas, solo con `includeSold`:** `ExchangeRateService.GetConvertedSalesAsync` de las ventas de la empresa (filtradas como en `GetSoldAsync`). Línea con coste = `CostOriginal`, valor = `NetProceedsOriginal`, resultado y %. En «Compras del periodo», solo la parte de los lotes del periodo (proporción de acciones). Si una venta es aproximada, va un aviso.
7. **Dividendos:** una línea por cobro (fecha, importe), si la vista los cuenta.
8. **Totales** con importes sin redondear, redondeados al final:
   - Invested = Σ coste;
   - Value = Σ valor de lotes y ventas;
   - Dividends = Σ dividendos;
   - rentabilidades = (Value − Invested) ÷ Invested y (Value + Dividends − Invested) ÷ Invested, × 100.

   Son las mismas fórmulas que `CompanyDetail.Calculate*` y `SoldPositionsSummary`, así que el total coincide con la fila.
9. **Orden de las líneas:** por fecha.
10. **El método no guarda nada.**

**Helper compartido:** se extrae de `GetClosingSummaryAsync` la obtención del precio de cierre de una empresa en una fecha (`GetCloseAtAsync`), sin cambiar su comportamiento.

## 4. Página `CompaniesList.razor`

- Estado: `expandedCompanyId`, `breakdown`, `isLoadingBreakdown` y `breakdownError`.
- **Flecha ▸/▾** delante del nombre (botón accesible con `aria-expanded`). El clic en el nombre hace lo mismo. Abrir otra cierra la anterior.
- **Al abrir:**
  - en la lista corta, `GetBreakdownAsync(company.Name, periodFilter, periodView, includeSold)`;
  - en la lista extendible, `GetBreakdownAsync(company.Name, SalesPeriodFilter.All, Purchases, includeSold)`.
- **Al recalcular la vista** (`ApplyPeriodAsync`, `SetIncludeSold`, `LoadCompanies`): si hay una empresa abierta y sigue en la lista, se vuelve a pedir; si no, se cierra.
- **Fila extra** `<tr class="breakdown-row"><td colspan="6">` con:
  - una tabla compacta: Fecha · Tipo · Acciones · Precio · Coste · Valor · Resultado;
  - la fila total en negrita, con el % por precio y, si toca, con dividendos;
  - los avisos;
  - el botón «Ver en operaciones» → `Navigation.NavigateTo($"/operations?company={Uri.EscapeDataString(name)}")`.
- **Importes** con `CurrencyFormatter.Format(…, breakdown.CurrencyCode)` y acciones con `ShareQuantity.Format`.
- **Ajuste de SPEC-01-11:** con «Incluir vendidas» y un periodo, `RefreshSoldAsync` pide además `GetSoldAsync(All)` para las filas de la lista extendible. `SoldInfo` usa el `Info` de la lista que se esté mostrando.

## 7. Casos límite

- **Empresa sin operaciones en la vista:** desglose vacío con el texto «Sin operaciones en esta vista».
- **Precio de cierre que falta:** se usa el actual, con aviso (como `GetClosingSummaryAsync`).
- **Lote partido:** solo la fila abierta en lotes; la cerrada va dentro de su venta (`SaleHistoryId`).
- **Empresa sin tipo de cambio:** el desglose funciona en su divisa.
