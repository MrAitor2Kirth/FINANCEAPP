## 1. Enfoque

Todo se calcula al leer, sin tocar el modelo ni la BD. La regla «con inversión» y los cálculos (promedio de yield, sectores, rentabilidad ponderada) viven en una clase estática nueva de `Services/` (como `OperationAmountCalculator`), para que la página solo pinte. La conversión a divisa base reutiliza `IExchangeRateService.GetConvertedTotalsAsync` **sin modificarlo** (lo usan también el Dashboard y «Total invertido»): se llama una segunda vez solo con las empresas con inversión.

## 2. Modelo de datos

Ninguno. Sin columnas, tablas ni cambios en `DatabaseSchemaUpgrader`.

## 3. Algoritmos

### 3.1 `Services/InvestedCompaniesSummary.cs` (nuevo, estático)
- `HasInvestment(CompanyDetail c)` → `c.TotalInvestedInitial > 0`.
- `GetInvested(IEnumerable<CompanyDetail> companies)` → lista de las que cumplen `HasInvestment`.
- `AverageDividendYield(IReadOnlyCollection<CompanyDetail> invested)` → `decimal?`: media simple de `DividendYield`; `null` si la lista está vacía.
- `WeightedReturnPercent(ConvertedCompanyTotals totals)` → `decimal?`: `null` si `totals.InvestedInitial <= 0`; si no, `Math.Round((totals.CurrentValue − totals.InvestedInitial) / totals.InvestedInitial × 100, 2, AwayFromZero)`. Es la media de las rentabilidades ponderada por la inversión convertida a la divisa base.

### 3.2 `CompaniesList.razor`
- Tras cargar `companies` y calcular `convertedTotals` (todas las empresas, para «Total invertido», sin cambios), se calculan `investedCompanies = GetInvested(companies)` e `investedTotals = await ExchangeRateService.GetConvertedTotalsAsync(investedCompanies)`.
- `visibleCompanies => isExtended ? companies : investedCompanies` (la tabla recorre esta lista).
- `uniqueSectorsCount` y `averageDividendYield` pasan a calcularse sobre `investedCompanies`; «Total empresas» muestra `investedCompanies.Count`.
- Tarjetas:
  - «Total empresas»: nota `de @companies.Count en el catálogo` si `investedCompanies.Count < companies.Count`.
  - «Dividend yield promedio»: «—» si no hay promedio.
  - Nueva «Rentabilidad media» (swatch propio, tras «Dividend yield promedio»): `▲/▼` + valor con `N2` y `%`, verde/rojo como «Beneficio total» de `SalesHistoryList`; «—» sin valor; nota con `investedTotals.MissingRateCompanies` como la de «Total invertido».
- Modo corto: si `investedCompanies.Count < companies.Count`, línea informativa «Mostrando N de M empresas (solo las que tienen inversión). Pulsa «Lista extendible» para ver todas.»; si `investedCompanies.Count == 0`, aviso «No hay empresas con inversión. Pulsa «Lista extendible» para ver todo el catálogo.» en lugar de la tabla.
